# Publication scope

## Public in MDPAR-docs

- Technical and hypothesis documents.
- Swagger operational manual and operational contract.
- Evaluation standards and hardware/evidence documentation.
- Canonical corpora used by retained C0–C12 protocols.
- Retained C0–C12 evidence runs and integrity index.
- Adapter dependency snapshot.
- Evidence-integrity verification utilities.

## Not public in this package

- Production Java source code or JAR.
- Private `mdpar-ai-adapter` application source.
- Provider credentials, API keys or other secrets.
- Private development history, deprecated iterations or internal IDE state.

## Claims

The package is evidence for the reported behavior of the frozen evaluated system. The Structural Universality Hypothesis remains a broader scientific hypothesis and should be described separately from the empirical status of individual C0–C12 results.
